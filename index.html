À propos du comptage

Quelques règles déjà actives dans le logiciel :

• Le même aliment ne compte qu'une fois sur toute la semaine.
 • Herbes, épices et thés/tisanes comptent pour 0,25 dans le total sur 30.
 • Un aliment déjà ajouté le même jour est refusé (message d'avertissement).
 • Seul un aliment présent dans la liste peut être ajouté.
 • Les badges colorés indiquent les vitamines majeures d'un aliment (survol ou tap pour le détail).
